| ⭐⭐⭐      | **Paleyes, Urma & Lawrence – Challenges in Deploying Machine Learning: a Survey of Case Studies**                 |    2020 | Great source for the statement: *training the model is not the hard part; deployment creates problems throughout the entire lifecycle.*                 | Deployment / production ([arXiv][5])                   |

| ⭐⭐       | **Baylor et al. – TFX: A TensorFlow-Based Production-Scale Machine Learning Platform**                            |    2017 | Early real-world end-to-end ML platform paper: data analysis → validation → training → evaluation → serving.                                            | Pipelines / automation ([SSL][9])                      |

| ⭐⭐       | **Mitchell et al. – Model Cards for Model Reporting**                                                             | 2018/19 | Similar idea for trained models: intended use, limitations and measured performance should travel with the model.                                       | Model registry / governance ([arXiv][13])              |
